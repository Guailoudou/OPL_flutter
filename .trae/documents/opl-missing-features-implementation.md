# OPL 缺失功能补齐实施计划

## 概述

根据功能设计文档和当前项目状态，本计划旨在补齐 OpenP2P Launcher (OPL) 还缺少的核心能力，同时考虑多端适配问题。

**当前已实现功能：**
- ✅ Node.js 后端服务（预设、公告、赞助、版本更新 API）
- ✅ 连接码解析与生成（标准、简化、多连接格式）
- ✅ 预设隧道页面
- ✅ 赞助列表展示
- ✅ 主程序更新检测
- ✅ 基础隧道管理（创建、编辑、删除、启用/禁用）

**目标平台：**
- 桌面端：Windows、Linux、macOS
- 移动端：Android、iOS

## Phase 2: 需求澄清

### 多端适配策略

**桌面端特有功能：**
- 系统托盘图标和菜单
- 开机自启动
- 安全中心排除（仅 Windows）
- 主题自定义（颜色选择器）

**移动端限制：**
- 无系统托盘（使用后台服务）
- 无开机自启动（使用系统广播）
- 无安全中心排除
- 简化主题设置（仅浅色/深色/跟随系统）

**跨平台通用功能：**
- 虚拟组网（EasyTier/OpenP2P）
- 进程管理
- 日志导出
- 网络诊断
- 运营商检测

## Phase 3: 实施计划

### 阶段一：核心功能补齐（P0）

#### 1. 虚拟组网功能

**目标：** 实现 EasyTier 和 OpenP2P 两种虚拟组网方案

**文件清单：**
- `lib/src/core/easytier_service.dart` - EasyTier 服务封装
- `lib/src/core/openp2p_network_service.dart` - OpenP2P 组网服务
- `lib/src/ui/pages/network_page.dart` - 组网页面（创建/加入网络）
- `lib/src/ui/widgets/network_card.dart` - 组网卡片组件

**实现要点：**
- EasyTier：基于命令行工具，支持创建/加入虚拟网络
- OpenP2P：基于现有隧道功能，扩展虚拟 IP 分配
- 支持 TCP/UDP 协议选择
- 实时显示节点列表和连接状态
- 自动分配虚拟 IP（10.0.23.x 网段）

**多端适配：**
- 桌面端：完整功能
- 移动端：仅支持加入网络（简化 UI）

#### 2. 进程管理增强

**目标：** 完善进程启动、停止、状态监控和异常处理

**文件清单：**
- `lib/src/state/process_manager.dart` - 统一进程管理器
- `lib/src/core/process_monitor.dart` - 进程监控器
- 修改 `lib/src/state/core_runner.dart` - 集成进程管理器

**实现要点：**
- 统一的进程生命周期管理
- 实时进程状态监控（运行中、已停止、异常）
- 异常自动重启机制（2 秒延迟）
- 端口占用检测和自动更换
- 进程输出日志解析和状态更新
- TCP/UDP 保活机制

**多端适配：**
- 桌面端：完整进程管理
- 移动端：使用 Android/iOS 原生服务

#### 3. 日志导出功能

**目标：** 支持将日志打包为 ZIP 文件导出

**文件清单：**
- `lib/src/services/log_export_service.dart` - 日志导出服务
- 修改 `lib/src/ui/pages/logs_page.dart` - 添加导出按钮

**实现要点：**
- 收集 opl.log、openp2p.log、config.json
- 使用 archive 包打包为 ZIP
- 支持分享功能（移动端）或保存文件（桌面端）
- 程序运行时禁止导出（防止文件锁定）

**多端适配：**
- 桌面端：保存到本地文件夹
- 移动端：使用系统分享功能

### 阶段二：用户体验优化（P1）

#### 4. 主题设置

**目标：** 支持浅色/深色/跟随系统主题切换

**文件清单：**
- `lib/src/core/theme_service.dart` - 主题服务
- `lib/src/core/theme_models.dart` - 主题数据模型
- 修改 `lib/src/app/app.dart` - 集成主题服务
- 修改 `lib/src/ui/pages/settings_page.dart` - 添加主题设置项

**实现要点：**
- 三种模式：浅色、深色、跟随系统
- 使用 Flutter 的 ThemeMode API
- 持久化用户选择
- 实时切换无需重启

**多端适配：**
- 全平台统一实现

#### 5. 开机自启动（桌面端）

**目标：** 支持系统启动时自动运行程序

**文件清单：**
- `lib/src/services/autostart_service.dart` - 自启动服务
- 修改 `lib/src/ui/pages/settings_page.dart` - 添加自启动开关

**实现要点：**
- Windows：注册表方式
- Linux：.desktop 文件方式
- macOS：LaunchAgent 方式
- 检测当前自启动状态
- 支持 UAC 提示优化（Windows）

**多端适配：**
- 桌面端：完整支持
- 移动端：不支持（隐藏设置项）

#### 6. 系统托盘（桌面端）

**目标：** 实现系统托盘图标和右键菜单

**文件清单：**
- `lib/src/services/tray_service.dart` - 托盘服务
- 修改 `lib/src/app/app.dart` - 集成托盘服务

**实现要点：**
- 使用 system_tray 包
- 托盘图标显示程序状态
- 右键菜单：显示窗口、退出
- 关闭窗口时最小化到托盘
- 首次关闭时询问用户偏好

**多端适配：**
- 桌面端：完整支持
- 移动端：不支持（使用后台服务）

### 阶段三：高级功能（P2）

#### 7. 网络诊断工具

**目标：** 提供网络连通性检测和 NAT 类型检测

**文件清单：**
- `lib/src/services/network_diagnostic_service.dart` - 网络诊断服务
- `lib/src/ui/pages/diagnostic_page.dart` - 诊断页面

**实现要点：**
- 网络连通性检测（ping 测试）
- NAT 类型检测（对称 NAT 警告）
- 延迟和丢包率测试
- 连接质量报告
- 历史记录保存

**多端适配：**
- 全平台统一实现

#### 8. 运营商检测警告

**目标：** 检测非主流运营商并提醒用户

**文件清单：**
- `lib/src/services/isp_detection_service.dart` - ISP 检测服务
- 修改 `lib/src/state/app_controller.dart` - 集成 ISP 检测

**实现要点：**
- 调用第三方 API 获取 IP 信息
- 识别主流运营商（电信、联通、移动）
- 非主流运营商警告提示
- 缓存检测结果
- 可配置是否启用

**多端适配：**
- 全平台统一实现

#### 9. 安全中心排除（仅 Windows）

**目标：** 自动将程序目录添加到 Windows Defender 排除列表

**文件清单：**
- `lib/src/services/defender_exclusion_service.dart` - Defender 排除服务
- 修改 `lib/src/ui/pages/settings_page.dart` - 添加排除选项

**实现要点：**
- 使用 PowerShell 命令添加排除
- 需要管理员权限
- 检测当前排除状态
- 失败时提供手动操作指引

**多端适配：**
- 仅 Windows：完整支持
- Linux/macOS：不支持（隐藏选项）
- 移动端：不支持（隐藏选项）

## 风险与缓解

### 风险 1：虚拟组网跨平台兼容性
- **风险：** EasyTier/OpenP2P 在不同平台行为差异
- **缓解：** 充分测试各平台，提供降级方案

### 风险 2：进程管理稳定性
- **风险：** 进程异常退出、端口占用等问题
- **缓解：** 完善异常处理，提供手动重启选项

### 风险 3：系统权限限制
- **风险：** 移动端权限限制导致部分功能不可用
- **缓解：** 功能降级，提供替代方案
